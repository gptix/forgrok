* Definition

The Air-gapped / Near-Airgapped CEO Pattern is the deliberate architectural choice to run the autonomous CEO agent (Withnail / Hermes) with extremely limited external connectivity.

Core rules:
- The agent primarily operates on local models and local data.
- Outbound network access is minimized and tightly controlled (currently limited to Telegram polling and occasional approved package updates).
- No general web browsing, email, or arbitrary API access is granted by default.
- Human / Grok remains the high-level strategic interface; the local agent executes within a hardened, mostly isolated environment.

This pattern is a direct implementation of Brian Roemmele’s Zero-Human Company (ZHC) principles applied to the Zero-Human Organization (ZHO) on the Raspberry Pi 5.

* Why it matters

- Maximizes privacy and reduces attack surface.
- Keeps the CEO agent’s reasoning grounded in the curated local knowledge base.
- Makes the system more robust to external service failures or rate limits.
- Aligns with the long-term goal of a mostly self-contained, high-trust autonomous executive.

* Current implementation notes

- Host: Raspberry Pi 5 (8GB)
- Primary LLM: local Ollama models (Hermes-oriented)
- Allowed external channel: Telegram (outbound polling only)
- Knowledge exposure: Selective (see Selective Knowledge Exposure node — to be created)
