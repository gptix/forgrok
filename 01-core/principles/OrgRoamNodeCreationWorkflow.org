* Purpose

Reliable, low-friction process for creating new org-roam nodes that avoids the common header and mode problems.

* Standard procedure for a new node

1. Create the file in the correct location under the numbered structure.
2. Open the file in Emacs.
3. *Immediately* ensure the buffer is in Org mode:
   - Check the mode line.
   - If it says Fundamental (or anything else), run =M-x org-mode= or =M-x normal-mode=.
4. Insert the standard metadata block at the top of the file:

   #+begin_example
   #+TITLE: Human Readable Title
   #+NODE-NAME: CleanPascalCaseName
   #+FILETAGS: :relevant:tags:
   #+ROAM_TAGS: space separated tags
   #+DATE: YYYY-MM-DD
   #+AUTHOR: George Taylor + Grok
   #+end_example

5. Leave exactly one blank line after the metadata block, then start the first heading (=* Overview= or similar).

6. Save the file (=C-x C-s=).

7. Run =M-x org-id-get-create=.
   - This will insert a =:PROPERTIES:= drawer with an =:ID:= under the first heading (the preferred style).

8. Save again.

* Important rules (learned the hard way)

- The buffer *must* be in Org mode before running any org-id or org-roam commands. Otherwise you get =org-element-at-point= errors.
- Do *not* put a file-level =:PROPERTIES:= drawer at the very top of the file unless you have a specific reason. Prefer the ID under the first heading.
- If a file-level properties drawer already exists:
  - Place point at the beginning of the file.
  - Delete any existing =:ID:= line inside it (or delete the whole drawer if it is empty/broken).
  - Make sure =#+TITLE:= and the other metadata lines start on their own lines *after* the =:END:= of any properties drawer.
- Never let =:END:= and =#+TITLE:= end up on the same line.

* After creating one or more nodes

- You may run =M-x org-roam-db-sync= at any convenient time.
- It is not required after every single node, but it *should* be run before the final git push at the end of a session so the database is consistent with what is being committed.

* Validation (Voight-Kampff)

During the end-of-session Voight-Kampff cycle, confirm that:

- New nodes follow the NODE-NAME convention (PascalCase, no spaces/hyphens/underscores).
- Headers are clean (no concatenated =:END:#+TITLE:= lines).
- The buffer was in Org mode when the ID was created.
- =org-roam-db-sync= has been run if any new nodes were added.
- The updated instructions in this node itself have been committed.
