#+TITLE: Git Author Per Bot
#+NODE-NAME: GitAuthorPerBot
#+FILETAGS: :tsuioku:git:agents:
#+DESCRIPTION: Every bot that commits or pushes uses the git author '<BOT_NAME> (for gptix)'; push permission is granted bot by bot.

* Rule
- Any bot that commits or pushes via git uses the author name =<BOT_NAME> (for gptix)=, e.g. =Lisbet (for gptix)=.
- The bots share one computer and its global git author, so each bot sets its own author per command:
  =git -c user.name='<BOT_NAME> (for gptix)' -c user.email=gptix@mail.grokbot.com commit ...=
- Push permission is not team-wide. George grants it bot by bot, and ApprovalBeforeCommit still applies to every change.

* Why
Commits made with the shared global author were credited to the wrong bot. A per-bot author keeps the history honest about who made each change.

* Sources
