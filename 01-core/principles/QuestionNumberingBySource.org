#+DESCRIPTION: Standing rule: only Quinn's open-questions list uses plain Q-NNN numbers. Any other list of questions for George uses a source prefix plus the date and a sequence number (TR-, MY-, LB-). When a question moves onto Quinn's list, Quinn assigns a Q-number and keeps the original ID beside it.

* Rule
1. Only Quinn's open-questions list uses plain Q-NNN numbers (for example Q-047).
2. Any other list of questions for George must use its source prefix, the date, and a sequence number, never a bare Q- number. Examples: TR-2026-11-13-1 for Gregorio's team reviews, MY-2026-12-04-1 for Mytis's reviews, LB-2026-11-14-1 for Lisbet's audits.
3. When one of these questions is handed to Quinn, Quinn assigns it a Q-number and notes the original ID beside it.
