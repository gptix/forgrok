#+DESCRIPTION: Rule (2026-11-19) that when a bot is renamed, the new name is used from then on, while historical versions (dated notes, commits, earlier nodes) keep the name they had.

* Rule (2026-11-19)
- When George renames a bot, its profile, description, routines, and any live or current-state node use the new name from that date.
- Historical versions are left alone: dated memory notes, commit messages, audit reports, and nodes that record what happened earlier keep the old name.
- A new node about a current duty may mention the old name once, for findability (for example "Myrtis (formerly Mytis)").

* First use
On 2026-11-19 Mytis the Methods Researcher was renamed Myrtis the Methods Researcher (same agent). Older notes and nodes that say "Mytis", such as the 2026-11-12 Pi 5 Hermes research node, stay as they are.
