# forgrok

Personal knowledge base and working repository for collaboration with Grok, local agents (Withnail / Hermes), and high-protein source material.

The knowledge base is called **Tsuioku** (追憶 — recollection). This GitHub repository is the remote mirror. The canonical working copy lives on the X230 at `~/local-side/`.

## Quick orientation

- **[STRUCTURE.md](STRUCTURE.md)** — authoritative directory map and design principles
- **[STATUS.md](STATUS.md)** — living operational snapshot
- **[BOOT.md](BOOT.md)** — session-start instructions for Grok
- **[08-skills/](08-skills/)** — executable processes (Voight-Kampff, node creation, GitHub inspection, …)

`ZHO-SCHEMA.md` is a historical compiler schema from the pre-renumbering `groki/` layout. It is not the current directory map.
