# forgrok

Personal knowledge base and working repository for collaboration with Grok, local agents (Withnail / Hermes), and high-protein source material.

## Quick orientation

The repository is organized by concern rather than by chronology.

- **[STRUCTURE.md](STRUCTURE.md)** — full layout and design principles  
- **[STATUS.md](STATUS.md)** — living operational snapshot  
- **[BOOT.md](BOOT.md)** — session-start instructions for Grok  

### Main areas

| Path | Purpose |
|------|---------|
| `01-core/` | Stable knowledge, memory protocols, ZHO doctrine, agent identity |
| `02-infrastructure/` | Hermes-pi, hardware, tools, procedures, scripts |
| `03-projects/` | Active projects (Withnail, AI Agent Consulting, Tarot, etc.) |
| `04-sources/` | Curated external high-protein content (Roemmele, Koerner Office, …) |
| `05-wiki/` | Wikified concepts, graphs, indexes |
| `06-raw/` | Unprocessed material |
| `07-sessions/` | Selected session exports and VK summaries |
| `08-skills/` | Reusable skill nodes (how-to processes) |
| `99-archive/` | Superseded or low-value material |

## Working copy

The canonical working copy lives on the X230 at `~/local-side/`.

Changes are made there, committed in small logical units, and pushed to this GitHub repository.
