* Purpose / When to use
Use this skill whenever the operator asks for (or you decide to provide) text for a *new* Tsuioku / org-roam node.

Typical trigger phrases:
- "Please provide text for a new Tsuioku node about …"
- "Make a new node for …"
- Any request that should result in a durable knowledge-base entry.

The output must be immediately usable: paste into a new buffer, ensure org-mode, dry-run, then finalize.

This skill is for a new file. A revision of a file already on =github-side= is an edit of that buffer. Do not wrap a revision in =#+PROPOSED_PATH:=. That would make =C-c n F= place a second file.

* Preconditions
- A PascalCase =NODE-NAME= with no spaces, hyphens, or underscores.
- A relative path under the knowledge-base root (=STRUCTURE.md=). Path must end in =.org=.
- The content is drafted.
- A brand-new top-level directory also needs =STRUCTURE.md= and possibly =BOOT.md=.

* Steps
1. Determine the relative path (example: =08-skills/GenerateTsuiokuNodeText.org=).
2. Choose the =NODE-NAME=.
3. Write a short =COMMIT_MSG=.
4. Produce one text block in this order. Line 3 is the sentinel. It is not optional.

#+begin_example
#+PROPOSED_PATH: <relative-path-from-repo-root>
#+COMMIT_MSG: <short commit message>
############ THIS LINE AND ALL ABOVE WILL BE DELETED, WITH NEW :PROPERTIES: DRAWER STARTING AT VERY BEGINNING OF FILE ###################
#+AUTHOR: George P. Taylor IX
#+CATEGORY: <appropriate category, e.g. 08-skills or 03-projects>
#+CREATED: [YYYY-MM-DD Day HH:MM]
#+LAST_MODIFIED: [YYYY-MM-DD Day HH:MM]
#+TITLE: Human-readable title
#+NODE-NAME: PascalCaseNodeName
#+FILETAGS: :tag1:tag2:tag3:
#+DESCRIPTION: One- or two-sentence summary of the node's purpose.
#+end_example

5. Critical rules, enforced by =my/org-roam-finalize-place-id-commit= in =02-infrastructure/emacs/forgrok-org-helpers.el=:
- Line 1 is =#+PROPOSED_PATH:=. No blank line and no other text before it.
- Line 2 is =#+COMMIT_MSG:=.
- Line 3 is the sentinel, exactly as shown. The helper deletes from point-min through that line only when the sentinel matches. Without it, the two keywords survive into the commit.
- Do not include a leading =:PROPERTIES:= drawer. The helper calls =org-id-get-create=.
- =NODE-NAME= is PascalCase. No spaces, hyphens, or underscores.
- Path ends in =.org=.
- Lasting keywords and the body go below the sentinel.

6. Hand the block to the operator. Say that =C-c n F= commits that one file and does not push.

7. Operator, on the T470s:
- Paste into a brand-new buffer. Not an existing file. Not an org-capture buffer.
- =M-x org-mode= if needed.
- =C-u C-c n F= dry-run. It must name the intended path and commit message, and leave the buffer unchanged.
- =C-c n F=. Confirm. The helper writes the file, puts =:ID:= at the top, updates the org-roam DB, stages that file, and commits. It does not push. It does not stage the inventory or any other file.
- Check the top of the buffer. =:PROPERTIES:= / =:ID:=, then =#+AUTHOR:=. No =PROPOSED_PATH=, no =COMMIT_MSG=, no sentinel.
- Other files (inventory, status) are a second commit, or an amend before the push. Then =git push github-side main=.

* Cross-links
Do not create a node in order to link to it.

- If the target already has an =:ID:=, paste =[[id:UUID][NodeName]]=. Look the UUID up in the target file. Do not run =C-c n f= on that name.
- =C-c n i= is safe only when the completion list shows the existing node. If a capture buffer opens, =C-c C-k=, then answer yes to "Delete file for aborted capture?". A capture ID is a new node.
- A listed essay with no org file gets a file link and a note. Example: inventory 025. Do not capture it in the same commit.

- Output: one paste block whose third line is the sentinel.

* Failure modes / Notes
- Sentinel missing: =C-c n F= commits =#+PROPOSED_PATH:= and =#+COMMIT_MSG:=. Essay 039, 2026-10-05, before the line was inserted by hand.
- Leading =:PROPERTIES:= drawer conflicts with the helper's ID placement.
- =NODE-NAME= with spaces or hyphens breaks =C-c n f= on this Emacs.
- Finishing a capture buffer (=C-c C-c=) creates a second node. Abort with =C-c C-k=.
- =C-c n F= does not update the inventory. A "pushed" claim that skips that file is wrong.
- Magit "Unmerged into github-side/main (1)" means the commit is local. Push it.
- Revisions of an existing file: edit in place, update =#+LAST_MODIFIED=, do not use this template.
