#+EXECUTIVE_SUMMARY: Transfer audio → ensure venv + faster-whisper on Pi → run logged transcription under named tmux session → monitor / retrieve result. Designed for multi-GB files that thrash the X230 disk.

* Purpose / When to use

Use this skill whenever a long or large audio file (especially YouTube captures or multi-hour recordings) needs Whisper transcription and would overload the X230’s disk or CPU.

The job runs entirely on hermes-pi. The X230 can be shut down or disconnected once the tmux session is started.

* Preconditions

- Tailscale is up and =hermes-pi= resolves.
- You can SSH as =gt-hermes@hermes-pi=.
- Audio file exists on the X230 (commonly under =~/Videos/=).
- Preferred model size decided (default: =small=).

* One-time setup (Pi)

Only needed the first time or after a clean rebuild of the transcription environment.

#+begin_src shell
ssh gt-hermes@hermes-pi
mkdir -p ~/transcription
cd ~/transcription
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install faster-whisper
# optional: sudo apt install -y ffmpeg   # if not already present
#+end_src

* Standard workflow

** 1. Transfer the audio (from X230)

#+begin_src shell
# Adjust source path and filename as needed
scp /path/to/audio.wav gt-hermes@hermes-pi:~/transcription/
#+end_src

** 2. Create or update the runner script (on Pi)

SSH in, then:

#+begin_src shell
cd ~/transcription
source venv/bin/activate
#+end_src

Paste the following (edit =AUDIO= and =MODEL_SIZE= if needed):
