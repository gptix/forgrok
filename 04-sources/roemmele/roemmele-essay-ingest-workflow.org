* Purpose

Repeatable path from a readmultiplex.com essay to a pushed org-roam node, then to ingested.

Refined 2026-07-29 through 2026-07-31 (essays 002–007). Driver no longer writes a skeleton =.org= (2026-07-31).
Smoothed 2026-10-05 from essay 039 (=HireGrokBotZhcExperience=): sentinel, explicit =git add=, no capture-as-link, inventory status kept in step with the commits.

* Status progression

| Status     | Meaning                                                                 |
|------------+-------------------------------------------------------------------------|
| listed     | URL and metadata recorded. No files.                                    |
| downloaded | SingleFile HTML in =html/=.                                             |
| cleaned    | Cleaned markdown and images exist. Not an inventory claim of knowledge. |
| pushed     | HTML, md, images, and the populated org node are on =github-side/main=. |
| ingested   | Cross-links exist, and the inventory row says so.                       |

The inventory cell is the status that counts. =#+STATUS:= inside the node should match it after each commit. =cleaned= on the node means "built from the cleaned markdown," not "inventory is still cleaned."

* Naming rule

=YYYY-MM-DD_Short-Hyphenated-Slug=

Date is the publication date. Same stem for the HTML, markdown, image directory, and org file.
Node name is PascalCase with no spaces, hyphens, or underscores (=HireGrokBotZhcExperience=).

* Preferred workflow (2026-10-05)

** 1. Select or add the inventory row
Open =roemmele-essays-inventory.org=. Use the next free id. Record URL, date, title, =reasonable_filename=, status =listed=.
Do not capture an org node yet.

** 2. SingleFile — human, logged in
Brave, logged in to https://readmultiplex.com. Open the URL. Scroll to the bottom.
SingleFile. Rename to =<reasonable_filename>.html=. Place in =04-sources/roemmele/html/=.
A fetch from outside the operator's browser is not a capture. readmultiplex often stops on a check page.

** 3. Driver — T470s
#+begin_src bash
cd ~/local-side/04-sources/roemmele
./scripts/ingest-roemmele-essay.sh <reasonable_filename>
#+end_src

Produces =cleaned/<name>.md=, =cleaned/<name>.raw.md=, and =images/<name>/=.
Does not write an =.org=.

** 4. Push mechanical files only
Stage explicit paths. Do not =git add -u= and do not commit a dirty tree. Essay 039's mechanical commit also appended a stray =Z= to a porch-pumpkin file.

#+begin_src bash
cd ~/local-side
git add 04-sources/roemmele/html/<name>.html
git add 04-sources/roemmele/cleaned/<name>.md
git add 04-sources/roemmele/cleaned/<name>.raw.md
git add 04-sources/roemmele/images/<name>/
git status
git commit -m "mechanical: essay <id> (<short title>)"
git push github-side main
#+end_src

=git status= before commit must not list unrelated files. Inventory may move to =cleaned= in this commit. Do not add an =.org=.

** 5. Grok writes the node
After those files are on =github-side/main=, Grok reads the cleaned markdown and returns one paste block per =GenerateTsuiokuNodeText=.

The block must start:

#+begin_example
#+PROPOSED_PATH: 04-sources/roemmele/cleaned/<name>.org
#+COMMIT_MSG: org node: essay <id> <short title>
############ THIS LINE AND ALL ABOVE WILL BE DELETED, WITH NEW :PROPERTIES: DRAWER STARTING AT VERY BEGINNING OF FILE ###################
#+end_example

Lasting keywords and the body go below the sentinel. Sections: Summary, Key Claims, Major Sections, Relevance, Notes, Related.
Author headcount and similar operating claims stay marked as the author's claims.
If a cross-link target already has an =:ID:=, put =[[id:UUID][NodeName]]= in Related now. If it does not, write "listed, no node yet" and a file link. Do not invent a capture.

** 6. Finalize — T470s, not a capture
Paste into a *new* buffer. =M-x org-mode=.
=C-u C-c n F= dry-run. =C-c n F= confirm.

The helper deletes through the sentinel, writes the file, adds =:ID:=, updates the org-roam DB, and commits that file only. It does not push.

If a capture buffer opens (=CAPTURE-…= in the mode line), =C-c C-k=, then yes to delete the capture file. Do not =C-c C-c=.

Check the top: =:PROPERTIES:= / =:ID:=, then =#+AUTHOR:=. Set =#+STATUS: pushed=.

** 7. Inventory to pushed, then push
#+begin_src bash
cd ~/local-side
git add 04-sources/roemmele/roemmele-essays-inventory.org
git commit -m "inventory: essay <id> pushed"
git push github-side main
#+end_src

Magit "Unmerged into github-side/main" means the commit is still local.

** 8. Cross-link, then ingested
Edit the existing node. =C-x C-f= the cleaned org file. Do not =C-c n f= if that offers to create.

- Existing node: paste =[[id:UUID][NodeName]]=, or =C-c n i= only if completion shows the existing node.
- Capture buffer: abort, delete the file.
- Listed essay with no file: file link plus "no node yet". Do not ingest it in this commit.

Commit the link edit. Then set the inventory row to =ingested= in its own commit and push.

* Success checklist

- [ ] HTML in =html/=
- [ ] Cleaned markdown and images on =github-side= before any =.org=
- [ ] Mechanical commit has no unrelated paths
- [ ] Node text included the sentinel
- [ ] After =C-c n F=, no =PROPOSED_PATH= or =COMMIT_MSG= in the file
- [ ] No capture file committed
- [ ] Inventory =pushed= only after the org node is on =main=
- [ ] Inventory =ingested= only after the cross-links are on =main=
- [ ] =#+STATUS:= matches the inventory cell
