* Purpose

Repeatable, low-friction workflow for turning a full Brian Roemmele essay from readmultiplex.com into durable knowledge-base artifacts.

Refined during processing of Essay 002–004 (2026-07-29/30).  
Higher-level driver script introduced 2026-07-30.  
Org-roam node population moved to Grok (after mechanical files are pushed) on 2026-07-30.

* Status Progression

| Status     | Meaning                                      |
|------------|----------------------------------------------|
| listed     | URL + metadata recorded                      |
| downloaded | SingleFile HTML present in =html/=           |
| cleaned    | Clean Markdown exists (org node may still be pending) |
| pushed     | HTML + md + images + org node all committed  |
| ingested   | Summary + cross-links + Infranodus material  |

* Preferred Workflow (2026-07-30 onward)

** 1. Select the essay

Open =roemmele-essays-inventory.org= and choose the next =listed= essay.  
Note its =reasonable_filename=.

** 2. Capture while logged in (SingleFile) — still human

1. Browser + SingleFile extension
2. Log in to https://readmultiplex.com
3. Open the essay URL and wait for full load
4. Run SingleFile
5. Rename to =<reasonable_filename>.html=
6. Place in =html/=

** 3. Run the driver script

#+begin_src bash
cd ~/local-side/04-sources/roemmele
./scripts/ingest-roemmele-essay.sh <reasonable_filename>
#+end_src

This produces the cleaned Markdown, extracts images, and creates a minimal skeleton .org (which we ignore for now).

** 4. Push the mechanical files only

Stage and push:
- the HTML
- the cleaned .md
- the images directory

Do **not** push the .org file yet.

** 5. Grok populates the org-roam node

Grok reads the cleaned .md and produces a complete, high-quality org-roam node (Summary, Key Claims, Major Sections, etc.).

** 6. Human review of the org node

In Emacs, open (`C-x C-f`)

#+begin_example
cleaned/<reasonable_filename>.org
#+end_example

Review the content Grok provided, make any desired edits, then save.

** 7. Commit the org node + update inventory

#+begin_src bash
cd ~/local-side
git add 04-sources/roemmele/cleaned/<reasonable_filename>.org
git add 04-sources/roemmele/roemmele-essays-inventory.org
git commit -m "org node + inventory: essay <id> (<short title>)"
git push
#+end_src

** SUCCESS checklist

- [ ] HTML in =html/=
- [ ] Cleaned =.md= in =cleaned/=
- [ ] Images under =images/<reasonable_filename>/=
- [ ] Fully populated org-roam node with valid =#+NODE-NAME:= (no spaces)
- [ ] Inventory status = pushed
- [ ] Everything on =github-side/main=
