* Purpose

Repeatable, low-friction workflow for turning a full Brian Roemmele essay from readmultiplex.com into durable knowledge-base artifacts.

Refined during processing of Essay 002 (2026-07-29) and Essay 003 (2026-07-30).  
Higher-level driver script introduced 2026-07-30 to collapse the mechanical steps.

* Status Progression

| Status     | Meaning                                      |
|------------|----------------------------------------------|
| listed     | URL + metadata recorded                      |
| downloaded | SingleFile HTML present in =html/=           |
| cleaned    | Clean Markdown + org-roam node exist         |
| pushed     | Everything committed and on remote           |
| ingested   | Summary + cross-links + Infranodus material  |

* Preferred Workflow (2026-07-30 onward)

** 1. Select the essay

Open =roemmele-essays-inventory.org= and choose the next =listed= essay.  
Note its =reasonable_filename=.

** 2. Capture while logged in (SingleFile) — still human

1. Browser + SingleFile extension
2. Log in to https://readmultiplex.com
3. Open the essay URL and wait for full load
4. Run SingleFile
5. Rename to =<reasonable_filename>.html=
6. Place in:

   #+begin_example
   04-sources/roemmele/html/<reasonable_filename>.html
   #+end_example

** 3. Run the driver script (one command)

#+begin_src bash
cd ~/local-side/04-sources/roemmele
./scripts/ingest-roemmele-essay.sh <reasonable_filename>
#+end_src

This single command performs:
- pandoc extraction + media download
- automated cleaning via =clean-roemmele-essay.sh=
- generation of a skeleton org-roam node with correct no-space =#+NODE-NAME:=

** 4. Human polish (two focused edits)

1. Visual pass on the cleaned Markdown:

   In Emacs, open (C-x C-f)

   #+begin_example
   cleaned/<reasonable_filename>.md
   #+end_example

2. Edit the org-roam node (fill Summary, Key Claims, SOURCE URL, DATE, improve TITLE if needed):

   In Emacs, open (C-x C-f)

   #+begin_example
   cleaned/<reasonable_filename>.org
   #+end_example

** 5. Update inventory

In =roemmele-essays-inventory.org= set status to =cleaned= (or =pushed= after the commit) and add a short dated note.

** 6. Commit & push

#+begin_src bash
cd ~/local-side
git add 04-sources/roemmele/
git commit -m "processed Roemmele essay <id> (<short title>)"
git push
#+end_src

** SUCCESS checklist

- [ ] HTML in =html/=
- [ ] Cleaned =.md= in =cleaned/=
- [ ] Org-roam node with valid =#+NODE-NAME:= (no spaces)
- [ ] Images under =images/<reasonable_filename>/=
- [ ] Inventory updated
- [ ] Commit visible on =github-side/main=

* Script Locations

- Driver (preferred): =04-sources/roemmele/scripts/ingest-roemmele-essay.sh=
- Cleaner (called by driver): =04-sources/roemmele/scripts/clean-roemmele-essay.sh=
- Git hooks: =04-sources/roemmele/scripts/git-hooks/=

* Notes on the driver script

- Derives a clean CamelCase =#+NODE-NAME:= automatically from the filename (date prefix stripped, hyphens removed).
- Will not overwrite an existing =.org= file (safe to re-run).
- Prints the exact remaining human steps at the end.
