#+NODE-NAME: RoemmeleEssayIngestWorkflow
#+TITLE: Roemmele Essay Ingest Workflow

* Purpose

Repeatable, low-friction workflow for turning a full Brian Roemmele essay from readmultiplex.com into durable knowledge-base artifacts.

Refined during processing of Essays 002–007 (2026-07-29 → 2026-07-31).
Higher-level driver script introduced 2026-07-30.
Org-roam node population moved entirely to Grok (after mechanical files are pushed) on 2026-07-30.
Skeleton .org generation removed from the driver script on 2026-07-31.

* Status Progression

| Status     | Meaning                                              |
|------------|------------------------------------------------------|
| listed     | URL + metadata recorded                              |
| downloaded | SingleFile HTML present in html/                     |
| cleaned    | Clean Markdown + images exist                        |
| pushed     | HTML + md + images + fully populated org node committed |
| ingested   | Summary + cross-links + further processing complete  |

* Naming Rule (permanent)

All essays use the pattern:

YYYY-MM-DD_Short-Hyphenated-Slug

- Date = publication date of the essay
- Slug = concise, hyphenated form of the title (no spaces, no special characters)

This name is used for the HTML, Markdown, images directory, and the final .org file.

* Preferred Workflow (2026-07-31 onward)

** 1. Select the essay
Open =roemmele-essays-inventory.org= and choose the next =listed= essay.
Note its =reasonable_filename=.

** 2. Capture while logged in (SingleFile) — human
1. Browser + SingleFile extension
2. Log in to https://readmultiplex.com
3. Open the essay URL and wait for full load
4. Run SingleFile
5. Rename to =<reasonable_filename>.html=
6. Place in =html/=

** 3. Run the driver script
#+begin_src bash
cd ~/local-side/04-sources/roemmele
./scripts/ingest-roemmele-essay.sh <reasonable_filename>
#+end_src

This produces:
- cleaned Markdown
- images directory and extracted images

It does *not* create any .org file.

** 4. Push the mechanical files only
Stage and push:
- the HTML
- the cleaned .md
- the images directory

Do *not* create or push any .org file yet.
Update the inventory status if desired at this stage.

** 5. Grok populates the org-roam node
After the mechanical files are on GitHub, Grok reads the cleaned .md and produces a complete, high-quality org-roam node (Summary, Key Claims, Major Sections, Relevance, etc.).

** 6. Human review of the org node
In Emacs:
=C-x C-f cleaned/<reasonable_filename>.org=

Paste Grok’s content, review, edit as needed, then save.

** 7. Commit the org node + final inventory update
#+begin_src bash
cd ~/local-side
git add 04-sources/roemmele/cleaned/<reasonable_filename>.org
git add 04-sources/roemmele/roemmele-essays-inventory.org
git commit -m "org node + inventory: essay <id> (<short title>)"
git push
#+end_src

* Success Checklist

- [ ] HTML in =html/=

- [ ] Fully populated org-roam node with valid =#+NODE-NAME:= (no spaces)
