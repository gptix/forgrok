What the Emacs function does

  1. Name: wpp/process-pumpkin-worksheet
  2. Compute a proposed path: 03-projects/porch-pumpkins/local-only/orders/YYYY-MM-DDThhmm-<Customer-Name>-pumpkins.org
  3. Write a markdown delivery order (print-friendly) next to it as …-delivery.md
  4. Save both under the local-only orders directory (gitignored; customer PII never goes to GitHub)
