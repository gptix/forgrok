# Pumpkin Varietal Minisite

Sub-project of `03-projects/porch-pumpkins/` for West Paces Pumpkins.

- Spec node: `PumpkinVarietalMinisite.org`
- Openable desk: `site/index.html` (search + table) and `site/worksheet.html`
- Catalog data: `site/data/varietals.json`
- Retrieved photos and customer orders: `local-only/` (gitignored)

On the T470s, place this directory at:

```
~/local-side/03-projects/porch-pumpkins/varietal-minisite/
```

Finalize the org node with `C-c n F`. Do not commit `local-only/` or third-party image dumps.
