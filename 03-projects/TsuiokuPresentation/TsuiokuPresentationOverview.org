* Purpose

Document and present the origin story of Tsuioku: the motivations (Roemmele, ZHO, Raspberry Pi), the debugging friction that made portable memory necessary, the successive strategies that were tried, the influences (Karpathy, Roam, InfraNodus), the construction of the three control surfaces, and the deliberate choice of Emacs over Obsidian.
    
* Artifacts

- PowerPoint version: =Tsuioku-Knowledge-Base.pptx= (same directory)
- Sitelet (preferred long-term form): =sitelet/= (self-contained HTML + CSS)

* Narrative Arc (12 sections)

1. The Spark — Roemmele, Zero Human Company, Raspberry Pi
2. The Hard Reality — setting up Withnail on the Pi
3. The Core Problem — knowledge that cannot travel dies
4. Early Strategies — specs as prompts → memory files → multiple projects
5. Standing on Shoulders — Karpathy, Roam approach, InfraNodus
6. Construction of Tsuioku — BOOT / STRUCTURE / STATUS
7. Current Structure — the numbered layout
8. Metadata & Automation — standardization + reducing drudgery
9. Emacs over Obsidian — why the integration matters
10. What Compounded — friction as data, structure enables agents, skills close the loop
11–12. Closing
