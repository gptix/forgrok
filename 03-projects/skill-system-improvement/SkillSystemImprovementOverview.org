* Purpose

Build and maintain a focused, high-signal skill library under =08-skills/= that automates, ensures quality, and simplifies recurring work across Tsuioku, Withnail/Hermes, Tarot Today, ZHO/HPC ingest, and document projects.

Skills follow current best practices: modular, single-purpose, explicit triggers + “NOT FOR” boundaries, progressive disclosure, human-expertise-first, and lifecycle management (create → use → measure → refine → promote/deprecate).

* Learning Cycle (to be encoded in skills)

1. After significant sessions or failures → run =CaptureLessonLearned=
2. When patterns repeat → propose skill edit via =SkillRefinementLoop= (produce → critique with score + gaps → refine)
3. Human (or explicit Withnail approval) gate before promotion
4. Measure usage / success; run =SkillHealthAudit= periodically
5. Deprecate or rewrite skills that no longer improve outcomes
