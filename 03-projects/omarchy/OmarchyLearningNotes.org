* What "learning Omarchy" means here

The T470s already has Omarchy installed. Priority is daily use:

- One menu (~=Super + Space= or the bar hotkey)
- Workspaces and tiling
- Themes
- Install / update path
- Built-in manual
- Battery, audio, and network panels (two internal packs; Ethernet + occasional Wi-Fi like the X230 pattern)

Do not start with hybrid CachyOS ISOs or "what is Omarchy 3.0" review videos.

On the machine: open the *Omarchy Manual* web app from the menu. That copy tracks the installed release. Public mirror: https://omarchy.org/manual

* Watch order

1. DHH — Omarchy Quattro (official 4.x intro)
2. NetworkChuck — 50 features after install
3. Dan Wahlin — 30-ish minutes on an old Intel laptop
4. LinuxBTW — Omarchy 4 tour (battery / audio / network chapters)
5. NetworkChuck — tiling mental model (skip the install hype)
6. typecraft — tiling for people who still reach for the mouse
7. DHH — unified menu (idea carries; chrome has moved)
8. DHH — Omarchy 3 45-minute tutorial (workflow only)
