* Purpose
Make Emacs on the ThinkPad T470s (hostname omarchy, user gptix) useful for Tsuioku the same way it is on the X230: Magit for the local-side repo, and C-c n F to place a draft node, attach a file-level ID, update org-roam, and commit without pushing.

X230 remains the canonical knowledge-base host. The T470s holds a working copy at ~/local-side (first rsync 2026-09-14). This node records the Emacs slice of that cutover, not a claim that the T470s is now authoritative.

* Draft format that C-c n F expects
The helper deletes from the top of the buffer through the sentinel line.

- Above the sentinel: only #+PROPOSED_PATH, #+COMMIT_MSG, and any throwaway instructions
- Below the sentinel: #+AUTHOR, #+TITLE, #+NODE-NAME, dates, tags, description, and body

#+NODE-NAME must be PascalCase with no spaces, hyphens, or underscores. C-c n f on this setup does not accept spaces in node names.

C-c n F commits locally and does not push. Push is a separate Magit step.
