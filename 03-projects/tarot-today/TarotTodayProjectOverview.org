* Long-term Vision

An application that lets a user photograph (or upload) a physical Tarot spread, has AI reliably identify the cards + orientation + layout, and returns a coherent, high-quality written interpretation.

Target platforms: Web, iOS, and Android.

Longer-term alignment with local-first / privacy values: support offline or self-hosted vision models where feasible.

* Recommended Next Steps (Ordered)

**1. Strengthen identification + add reading generation**
- Keep the strong identification instruction
- Raise =max_tokens=
- Ask for a short coherent interpretation after listing the cards
- Optionally request structured JSON for the cards

**2. Add a “question / intention” field**
- Even a simple optional text input dramatically improves reading quality

**3. Reduce key friction** (optional but valuable)
- Clearer instructions for obtaining an OpenRouter key
- Or explore temporary free-credit paths

**4. Structured output**
- Move from free-text list → JSON so later UI, history, and correction features become easy

**5. Decide production path**
- Stay with static + OpenRouter for rapid iteration, or
- Move to a small backend when more control / privacy / multi-step pipelines are needed

**6. Multi-platform**
- PWA first (already works on phone browsers)
- Then Flutter / Expo / Capacitor for store distribution
