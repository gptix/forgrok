* What the App Actually Does Today

A minimal, dark-themed single-page web app that:

1. Asks the user for an OpenRouter API key (stored in =localStorage=).
2. Lets the user upload an image of Tarot cards (with live preview).
3. On “Analyze Image”, converts the image to base64 and sends it to OpenRouter.
4. Uses the model ="openrouter/free"=.
5. Returns a short text response focused *only on card identification*.

There is *no full interpretation / reading* yet. The current prompt deliberately limits the model to listing the cards.

* Exact Current Prompt

#+begin_src text
You are analyzing a photograph of tarot cards.

Instructions:
1. Identify every visible tarot card using standard Rider-Waite names.
2. For each card, note whether it appears upright or reversed (if you can tell).
3. List the cards clearly, one per line.
4. If no tarot cards are visible, just say: "No tarot cards detected."

Respond only with the list of cards or the "No tarot cards detected" message. Do not add extra explanation.
#+end_src

Model parameters:
- =max_tokens: 50=
- =temperature: 0.1=
