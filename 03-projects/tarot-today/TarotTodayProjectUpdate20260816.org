* Additional image problems identified (2026-08-14 session)

Beyond the existing checks (no cards, non-tarot cards, wrong count, duplicates), the following should be detected:

- Card orientation / inversion (critical for meaning).
- Partial occlusion or cropping.
- Extreme perspective / camera tilt.
- Reflections, glare, or plastic sleeves.
- Mixed or non-standard decks.
- Table clutter / overlapping cards.
- Strong lighting gradients or color casts.
- Low resolution / heavy compression.
- Multiple spreads in one image.

Recommended pipeline: quality gate → instance detection + classification → orientation → consistency checks → confidence scoring. Fail gracefully with specific feedback.

* Reading layer design

Once a spread is validated, support:

- Multiple lengths: Quick, Standard, Deep, Journal-style.
- Multiple schools: Rider-Waite traditional, Marseille, Thoth, Psychological/Jungian, Modern therapeutic, Personal (user-history tuned).
- Formats: plain text, structured markdown/HTML, audio (TTS), shareable image/PDF, later short video.
- Attractive related images (public-domain RWS, style-transferred user cards, atmospheric backgrounds).

* Feature prioritization

High leverage (near-term):
- Multiple reading lengths + 1–2 distinct interpretive voices.
- Local (or optional cloud) save of spreads + readings.
- Simple personal pattern analysis.

Medium-term:
- Private-deck fine-tuning / few-shot adaptation.
- Group/family pattern views (opt-in).
- Custom deck design helper.

Later / monetization:
- Premium visual packs.
- Full custom-deck → print pipeline.

* Custom decks

Printing partners (2026):
- MakePlayingCards (MPC) — best for prototypes (MOQ 1).
- Shuffled Ink — US-based, small runs.
- Acelion, PrintNinja, WJPC — larger commercial runs.

Maker/DIY routes: home print + laminate, blank card stock + adhesive, local digital press, POD single decks, then offset at 200–500 units.

* Mobile distribution

Apple: $99/year Developer Program; iOS 26 SDK required; typical review 24–48 h (longer for novel AI features). Emphasize computer-vision + reflection journal angle to reduce “fortune-telling” scrutiny.

Android: $25 one-time; AAB required; new personal accounts need 14-day closed test with ≥12 testers before production access. First submissions often 7–14 days.

Practical path: high-quality PWA first, then native shells (Capacitor / Flutter / React Native) once recognition + reading quality are strong.
