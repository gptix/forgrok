* Important note

The current prototype requires a free OpenRouter API key.
Anyone can create one at https://openrouter.ai/keys (no credit card needed for the free tier).

* Web instructions

1. Open a browser and go to:
   https://huggingface.co/spaces/gptix/tarot-today

2. In the “OpenRouter API Key” field, paste your key (it starts with =sk-or-...=).
   The key is saved in your browser so you usually only need to enter it once.

3. Click “Upload image” and select a photo of one or more Tarot cards.

4. Click “Analyze Image”.

5. The model will return the names of the cards it recognizes (and orientation when it can tell).

Tips:
- Clear, well-lit photos of standard Rider-Waite style cards work best.
- Simple spreads (1–3 cards) are currently the most reliable.
- Larger spreads (especially Celtic Cross) may sometimes return an empty response with the free model.

* Apple (iPhone / iPad) instructions

1. Open Safari (or any browser) and go to:
   https://huggingface.co/spaces/gptix/tarot-today

2. Paste your OpenRouter API key into the key field.

3. Tap “Upload image”.

4. You can either:
   - Choose an existing photo from your Photos library, or
   - Take a new photo with the camera.

5. Tap “Analyze Image” and wait for the result.

Notes for Apple users:
- Works in Safari and most other browsers.
- For best results, photograph the cards in good light and try to keep them relatively flat and fully visible.
- You can add the page to your Home Screen (Share → Add to Home Screen) for quicker access.

* Android instructions

1. Open Chrome (or any browser) and go to:
   https://huggingface.co/spaces/gptix/tarot-today

2. Paste your OpenRouter API key into the key field.

3. Tap “Upload image”.

4. You can either:
   - Select an existing photo from your gallery, or
   - Take a new photo with the camera.

5. Tap “Analyze Image” and wait for the result.

Notes for Android users:
- Works in Chrome and most other browsers.
- You can add a shortcut to your home screen (menu → “Add to Home screen”) for convenience.
- Good lighting and a relatively straight-on photo improve recognition accuracy.

* Current limitations (please set expectations)

- This is an early prototype.
- It currently only identifies cards; it does not yet give a full reading or interpretation.
- The free model can occasionally return empty results, especially with very dense spreads.
- Best results are obtained with clear photos of classic Rider-Waite-Smith style decks.
